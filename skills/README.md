# Skills

在这里为每个 skill 建立独立文件夹，并使用 `SKILL.md` 作为入口。

开始添加时，可复制 [`../templates/skill/SKILL.md`](../templates/skill/SKILL.md)。

## 已收录

| Skill | 用途 | 调用示例 |
| --- | --- | --- |
| [零基础课程讲义](zero-foundation-course/SKILL.md) | 只给课程名，依据经典教材生成循序渐进的中文讲义，包含前置知识、例题、习题详解与综合应用 | `$zero-foundation-course 线性代数` |

该技能提炼通用教学方法，新课程的内容和案例重新设计，不依赖原始样例讲义。
