# 讲义验收清单

本清单用于检查实际讲义质量，不以固定用词、章节数或字数评分。

## 触发与范围

- 只给课程名时是否可以按合理默认值开始，而不是反复索要信息？
- 只问一道题或一个概念时，是否仍遵循该窄范围？
- 是否遵守用户指定的目标和篇幅，没有擅自加入考试要求或陌生项目？
- 新课程是否独立选材和设计，而不是改名套用其他课程的内容？

## 前置知识与递进

- 选一个核心概念，向前追溯它依赖的术语、符号、方法或工具；是否都已经解释？
- 读者能否从第 0 章或前文出发，理解一个核心例题，再独立完成同类练习？
- 困难内容是否给出足够中间步骤，而非用“显然”“自行查阅”跳过？
- 综合任务需要的能力是否由此前各章实际教过？

## 内容与依据

- 教材和课程来源是否真实？“已核验”“已阅读”“最新版”等表述是否有实际依据？
- 来源的作用是否明确，正文是否仍可独立学习？
- 任选一个核心例题和对应习题重新计算、逐步推理或验证结果。题目条件、解答与结论是否一致？
- 公式、结论和类比是否写清适用范围？有争议的解释是否体现证据与边界？
- 新设计的任务是否适合该学科，而非机械要求代码、实验或定量计算？
- 代码和操作是否可复现？未运行或无法验证的部分是否如实标记？

## 完整性与交付

- 核心章节有实际正文、示范、练习与解答，是否存在用目录代替后半部分的情况？
- 题号与解答是否一一对应，开放题是否给出评价依据？
- 附录是否便于复习，并且没有突然引入大量未讲解知识？
- 文件、链接、目录、编号、中文、公式与图表是否可以正常使用？
- 分次生成时，是否明确完成范围和接续点？当前文件的命名是否准确反映完整程度？

## 可复用的试用请求

以下请求用于后续试用，不是原始样例中的内容，也不预设这些课程的具体教材或答案。

| 输入 | 需要观察的行为 |
| --- | --- |
| `$zero-foundation-course 线性代数` | 直接开始；补必要的代数和符号；给完整知识路径、逐步例题与练习解析 |
| `中国古代史，完全零基础，给我系统讲义。` | 以时序、语境、材料和论证组织；不强制数学公式或编程项目 |
| `Python，零基础，最后想做一个个人记账小工具。` | 从基本操作补起；各章逐步支撑用户目标；代码有运行方法和结果说明 |
| `按上次的零基础讲义模式：宏观经济学。现在不能联网。` | 不声称已检索或核验版本；说明来源信息的实际状态，仍提供可写部分 |
| `只讲清楚导数是什么，先不要整套讲义。` | 收缩为单概念讲解，保留必要直觉和例子，不强行生成整门课 |
| `继续上一份讲义。` | 根据已保存的目录与完成状态接续，不重写开头、不把未完成稿说成完整稿 |
