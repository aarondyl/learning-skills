# 讲义教学骨架

这是跨学科的编写指南。课程的目录、例题、练习、综合任务与参考来源均需重新设计，不从其他课程的讲义搬运。

## 全书结构

| 部分 | 应解决的问题 | 写作要求 |
| --- | --- | --- |
| 标题与副标题 | 这是什么课，学到哪里？ | 明确课程和能力终点，避免空泛承诺 |
| 前言 | 适合谁，怎么学？ | 说明默认基础、学习方法、实际范围与必要补课 |
| 参考依据 | 为什么按这个体系组织？ | 主教材、补充来源、采用范围与核验情况 |
| 完整目录与路径 | 从哪里到哪里？ | 展示知识依赖、核心路线与可选拓展 |
| 第 0 章或基础补充 | 我真的能开始吗？ | 补足本课要用到的符号、方法和工具 |
| 各章正文 | 怎么理解、怎么使用？ | 目标、解释、示范、易错点、阶段回顾 |
| 习题与解答 | 我是否学会了？ | 题目与解析分区，难度逐步增加 |
| 综合应用 | 所学能否连成整体？ | 可分阶段完成的任务与验收方式 |
| 附录 | 日后如何快速复习？ | 按需收录概念、公式、方法、术语或工具速查 |
| 后续学习 | 接下来学什么，为什么？ | 给出进入进阶内容的门槛和具体路径 |

不固定章节数、页数或字数。篇幅应由学科范围与解释深度决定。

## 先做一张依赖表

在撰写前明确各章需要什么和产出什么。例如表中一行应能说明：

> 读者已会哪些最小技能 → 本章解决什么问题 → 能独立完成什么 → 下一章或综合任务如何使用它。

若一行需要读者掌握尚未出现的概念，调整顺序，或在本章前补短节。最终目录可以不同于教材目录，但不能遗漏达成终点所需的核心知识。

## 每章的建议组织

### 本章要点

用“能解释……的区别”“能独立算出……”“能依据材料论证……”这样的可检验表述。不要只有“了解相关知识”。

### 开场问题

从一个真实困惑或简单任务进入。读者应该知道本章为什么值得学，而不是先收到一串术语。

### 核心小节

每个核心小节完成一段从直觉到应用的推理。定义必须准确，解释必须通俗，两者缺一不可。

- 先解释对象与用途，再引入符号和规则。
- 类比后回到学科语言，说明哪些对应关系成立、哪些不成立。
- 提供与关键能力相匹配的完整示范；多个不同方法可用时说明取舍。
- 用反例或对比澄清容易混淆的概念。
- 从本节结论自然引出下一节，避免成为互不关联的知识卡片。

### 例题或分析示范

**理工与定量课程**：题目 → 已知与目标 → 方法选择 → 逐步推导或运算 → 单位、数量级或代回检查 → 一般方法 → 常见错误。

**程序与工具课程**：最小输入 → 代码或操作 → 每一步发生什么 → 预期结果 → 验证 → 常见错误与定位。

**人文与社会科学课程**：问题 → 材料及出处 → 语境与概念 → 证据支持什么 → 如何形成解释 → 反证或其他解释 → 结论边界。

开放问题不必有唯一答案，但必须说明哪些证据和推理使回答更可靠。

### 本章小结

回顾概念之间的关系、解题或分析方法，以及本章如何推动综合任务。不要仅把小节标题再列一遍。

### 本章习题

按实际需要覆盖以下层次：

1. 用自己的话解释或比较核心概念。
2. 在熟悉条件下独立完成基础任务。
3. 换一个条件、材料或情境，判断原方法是否仍成立。
4. 将本章与前面知识结合，解决一个小问题。

新出现的技巧先示范再考查；需要额外知识的题标记为拓展。

### 习题解答

保留题号的一一对应。给出解答依据和关键步骤，而不是只贴结果或让读者去教材里找。

- 计算题说明为什么选这个公式、条件是否满足、结果怎么检查。
- 操作题列出应看到的现象和与结果不符时的诊断线索。
- 论述题给出证据链、评价标准和可接受的替代观点。

## 把“零基础”落实到文字

避免只写“代入公式可得”“显然”“由常识可知”就跨过关键步骤。对新手来说，中间过程本身就是要学的内容。

每次出现新的表达形式，教会读者怎么读它。例如一个表格要说明横纵列的含义，一个图要说明方向和尺度，一段程序要说明输入、输出和状态变化。

不要将补基础变成另一套百科全书。只补当前所需的最小闭环，并告诉读者哪些内容暂时不用掌握。

## 综合任务的递进

依据本课特点选择分析、证明、计算、观察、创作或实现；没有必要强行安排编程。

每个阶段应包含：

- 本阶段要得到的具体结果及所需前置章节；
- 需要准备的材料、数据或工具及其来源；
- 从当前能力出发可跟随的步骤；
- 可检查的中间结果与最终验收标准；
- 失败、矛盾或结果偏差的可能原因；
- 这一阶段的简化假设与下一阶段要补的能力。

最后用一张关系表或连贯说明，把各章知识映射到成果的不同部分。避免只有“请自行完成一个项目”的结尾。

## 复习与排版

附录服务于检索，不引入一批正文从未解释的新知识。公式附条件，术语附简释，方法附适用场景；外语对照仅在有学习价值时加入。

导出时使用清楚的标题层级、稳定的编号、适合中文和公式的字体。避免表格过宽、代码被截断、公式失去上下标、标题孤立在页末；正文定稿后再更新目录页码。
